# PainKiller Labs — website logo pack

Three approved designs are included: the embossed circular badge, flat circular badge, and the selected **expanded-facets** horizontal logo with capital K.

| Design | Full-vector SVG | Transparent PNG widths |
| --- | --- | --- |
| Embossed badge | `svg/painkiller-labs-embossed.svg` | 512, 1024, 2048 |
| Flat badge | `svg/painkiller-labs-flat.svg` | 512, 1024, 2048 |
| Horizontal logo | `svg/painkiller-labs-horizontal.svg` | 688, 1376, 2752 |

The badges retain their dark circular interiors; the area outside each badge is transparent. The horizontal logo has a transparent background and a tighter canvas for easier placement in a website header.

`originals/` contains PNG copies with the supplied backgrounds and original framing. `vector-previews/` shows the SVG renderings for comparison.

## Website use

- Use the horizontal PNG for a lightweight website header. Its light text is intended for a dark background.
- Use the flat SVG when you want a crisp, scalable circular brand mark.
- Use the embossed PNG when the exact photographic finish matters. It is substantially lighter than the detailed embossed SVG.
- Preserve each file's aspect ratio. Avoid stretching width and height independently.

## What is vector and what is preserved

All three SVGs contain actual vector paths, with no embedded raster images, external files, or font dependencies. The horizontal lettering is the original outlined lettering from the selected design. Its gold bee has been vector-traced from the original artwork. The circular badges have been reconstructed from the approved JPGs: lettering, rings, bee details and shading are paths.

Vector conversion approximates raster edges, fine texture, and colour transitions. The embossed SVG uses layered tonal contours to retain the metallic appearance; it is not a procedural 3D model. The flat SVG removes JPEG noise and uses a restrained neutral palette. PNGs in `png/` preserve the approved source appearance while adding transparent outer backgrounds. The unmodified-background PNGs are in `originals/`.

The circular source images are 1024 × 1024. Their 2048 PNGs are enlarged exports, not additional original detail. The horizontal PNGs retain the original raster bee; the 2752 export is likewise enlarged. Use the SVG when arbitrary vector scaling is required.

Sources were left unchanged. No website files were replaced or published.
